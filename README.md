# ModemControl

تطبيق أندرويد (Kotlin) للتحكم بالمودم عبر إدخال عنوان IP، مع قفل بنمط (Pattern Lock) من الإعدادات.

## المزايا
- إدخال IP واسم المستخدم وكلمة المرور (تُخزَّن مشفّرة).
- اختبار الاتصال، وفتح لوحة المودم داخل التطبيق (تعمل مع أي موديل).
- إعادة تشغيل المودم بطلب HTTP تحدده من الإعدادات (المسار + GET/POST + جسم الطلب).
- قفل نمط 3×3: تعيين، تغيير، إزالة. يُحفظ كـ hash مملّح، ويُقفل 30 ثانية بعد 5 محاولات خاطئة، ويُطلب من جديد عند الرجوع من الخلفية.

- مفتاح **قطع الإنترنت عن كل الأجهزة** في الشاشة الرئيسية: يرسل طلب القطع أو الاستعادة المحدد في الإعدادات، فيسري على الأجهزة المتصلة الآن والتي تتصل لاحقاً.
  - اضبط الطلبين من الإعدادات ← "قطع الإنترنت عن كل الأجهزة" (مسار + GET/POST + جسم).
  - افحص الطلب من لوحة المودم (DevTools ← Network) عند الضغط على زر فصل/اتصال WAN، أو تفعيل فلتر MAC بوضع القائمة البيضاء الفارغة.
  - يستخدم الطلب جلسة لوحة المودم (الكوكيز) إن كنت مسجّلاً الدخول فيها.
  - **أجهزة مستثناة**: أضف اسم وعنوان MAC للجهاز في الإعدادات ← "أجهزة مستثناة من القطع"، وضع `{MACS}` أو `{MACS_JSON}` في مسار/جسم طلب القطع. يعمل مع طلب فلتر MAC بوضع القائمة البيضاء فقط (لا مع فصل WAN). إن عدّلت القائمة والقطع مفعّل يُعاد إرسال الطلب تلقائياً.
  - حالة المفتاح هي آخر أمر نجح إرساله، فالتطبيق لا يقرأ الحالة الفعلية من المودم.

## البناء
- افتح المشروع في Android Studio ثم Run، أو
- ادفعه إلى GitHub وسيبني **GitHub Actions** ملف APK تلقائياً (تبويب Actions ← Artifacts).

## ملاحظات
- أمر إعادة التشغيل يختلف حسب موديل المودم، افحص طلب الزر في لوحة المودم (DevTools ← Network) وضع مساره في الإعدادات.
- التطبيق يسمح بـ HTTP غير المشفّر لأن المودمات المحلية لا تدعم HTTPS غالباً. استخدمه على شبكتك فقط.
